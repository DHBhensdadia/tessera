# Tessera against ITC-2007

What Tessera's model makes of the 21 curriculum-based course timetabling instances from the second International Timetabling Competition — real timetables from the University of Udine.

Generated by `tessera fidelity --suite cbctt` from the same code that performs the import, against the instances pinned in [`scripts/itc2007-instances.sha256`](../../scripts/itc2007-instances.sha256).

## The short version

**19 of the 21 instances are solved**, and every solution is confirmed feasible and complete by the validator, which shares none of the solver's logic.

**The teaching structure crosses intact.** That is worth stating next to the ITC-2019 report, which had to drop all 52,254 of its classes: a Tessera session must be taught to a student group, and those instances state individual student enrolments with no programme tree to hang one on. **A CB-CTT curriculum is a cohort**, so the barrier is simply absent here. Courses, lectures, teachers, curricula, rooms and the week all map with nothing lost.

What does not map is small and named: the four soft constraints a CB-CTT solution is *scored* on — this phase places lectures and weighs nothing — and course-level unavailability where the teacher teaches more than one course, which cannot be carried without forbidding their other courses too.

**And one rule costs more than the rest combined.** 1 instance is **provably impossible** under Tessera — not unsolved, impossible. See below.

## Where Tessera is stricter than the competition

CB-CTT scores room capacity as a **soft** cost: put eighty students in a room for sixty and pay twenty points. Tessera makes it an invariant — *capacity is a fact about the building, not a cost to weigh against convenience* — so the same placement is refused outright.

The instances were built by people for whom overfilling was legal. So this is not a difference of opinion about a benchmark; it is the difference between two models, and here is what it costs:

### `comp01` cannot be timetabled at all

**64 lectures need a room seating at least 31, and the whole week contains 60 such room-periods.** Short by 4.

That is a proof, not a solver giving up: no arrangement of anything can put 64 lectures into 60 places. The competition's own documentation states every ITC-2007 instance has at least one feasible solution — and it does, *under CB-CTT's rules*, where the overflow is paid for rather than forbidden.

### And one more that capacity makes hard without making impossible

**`comp20`** was not solved in 300 seconds. No counting argument proves it impossible, and with capacity relaxed to CB-CTT's soft reading the same instance solves — so the hard rule is implicated, but this one may simply be a search problem rather than an arithmetic one. 4.4 is where that is addressed.

## What the mapping drops

| | across all instances | |
|---|---:|---|
| unavailability | 3,123 | names a course whose teacher teaches others; blocking the teacher would forbid those too, which the instance does not say |
| soft constraints | 84 | RoomCapacity, MinimumWorkingDays, CurriculumCompactness and RoomStability are what a CB-CTT solution is *scored* on; 4.2 places lectures and does not weigh them, and 4.5 scores an instance as written rather than as imported |

## What this says about Tessera

**Hard capacity is a real position with a real cost.** It is defensible — a room that seats sixty seats sixty, and a timetable that pretends otherwise is one somebody discovers at the door. It also means Tessera would refuse a timetable a real university ran, because `comp01` is a real timetable that Udine ran. Both of those are true and the second is not a reason to abandon the first; it is a reason to say so where a reader can see it.

**The competition's guarantee does not transfer, and that is the useful finding.** *Every ITC-2007 instance has at least one feasible solution* is true of CB-CTT and false of Tessera, by four lectures, on one instance out of twenty-one.

## Reproducing this

```bash
tessera fidelity --suite cbctt --instances /path/to/ITC-2007
```

The instances are served openly by the competition's own site; `scripts/itc2007-instances.sha256` records the SHA-256 of all 21, so a re-issued or corrupted file is caught rather than silently parsed.
